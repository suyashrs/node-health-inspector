# Node Health Inspector

A Python-based IT diagnostic tool for collecting and analyzing endpoint system health information.

## Project Goal

The goal of this project is to automate common diagnostic checks performed by IT support technicians, including: 

- System information
- CPU and memory usage
- Disk health
- Network Connectivity 
- Service Status
- Health reporting 

This project is being developed incrementally using OOP principles, testing, and documented using tickets.

## Current Status 

**Version:** 0.1 - In Development

Current milestone: 

- IT-001: System Inventory Scanner

## Planned Features

- System inventory collection
- Configurable health thresholds
- Network diagnostics
- Service monitoring 
- JSON and CSV reporting
- Remote endpoint scanning
